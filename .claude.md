# ARGUS - Claude Code Instructions

# ============================================================
# PROJECT
# ============================================================

Project Name:
Argus

Description:
A Secure Code Review Platform built using Django.

Purpose:
Detect security vulnerabilities using Bandit, Semgrep, Safety, pip-audit, and a custom AST Engine.

This project is inspired by:

- GitHub Advanced Security
- SonarQube
- Snyk

The goal is to become a professional Secure Code Review Platform suitable for real-world security teams.

Always prioritize:

- Clean architecture
- Maintainability
- Modularity
- Readability
- Performance

over flashy UI.

Work only on the currently assigned feature.

- Dashboard

# ============================================================
# DEVELOPMENT PHILOSOPHY
# ============================================================

Never redesign an entire page.

Always improve existing code.

Always preserve working functionality.

Every task should leave the project in a working state.

Small incremental improvements are preferred over large rewrites.

Do not perform unrelated refactoring.

Only modify what has been requested.

Prefer improving individual components instead of entire pages.
