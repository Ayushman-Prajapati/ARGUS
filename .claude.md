# ARGUS - Claude Code Instructions

# ============================================================
# PROJECT
# ============================================================

Project Name:
ARGUS

Description:
A Secure Code Review Platform built using Django.

Purpose:
Detect security vulnerabilities using multiple analysis engines including:

- Bandit
- Semgrep
- Safety
- pip-audit
- Custom ARGUS AST Engine

ARGUS is inspired by:

- GitHub Advanced Security
- SonarQube
- Snyk

The objective is to build a production-quality Secure Code Review Platform suitable for real-world security teams.

Primary priorities:

1. Security
2. Clean Architecture
3. Maintainability
4. Modularity
5. Performance
6. Extensibility
7. Readability

UI improvements should never compromise architecture.

# ============================================================
# AST ENGINE PRINCIPLES
# ============================================================

The ARGUS AST Engine is the core differentiator of the project.

Prioritize:

- Extensible architecture
- Modular rules
- Independent scanners
- Reusable utilities
- Low coupling
- High cohesion

Never hardcode rule logic inside the engine.

The engine should discover and execute rules through a registry.

Each rule must:

- inspect AST nodes
- return findings
- remain independent
- be individually testable

Adding a new rule should require minimal changes outside the rule itself.
